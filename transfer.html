Transfert

Transférer vers un autre appareil

Copier vos données vers un autre ordinateur ou un téléphone.

La méthode la plus simple : une sauvegarde
  1. Sur cet ordinateur : Paramètres › Sauvegarde › Enregistrer la sauvegarde, sur une clé USB par exemple.
  2. Installez Passory sur l'autre appareil et créez un coffre.
  3. Sur l'autre appareil : Paramètres › Sauvegarde › Ajouter à mon coffre, avec la même phrase de passe.

Transfert direct par câble Expérimental

Envoie uniquement des mots de passe, chiffrés de bout en bout, entre deux appareils reliés par un câble USB. Pour l'instant, cette connexion ne fonctionne qu'avec un téléphone Android relié en mode développeur : pour un autre ordinateur, utilisez la sauvegarde ci-dessus.

Prêt — choisissez les mots de passe puis cliquez sur « Attendre l'autre appareil »
Étapes
  1. Reliez les deux appareils avec le câble USB.
  2. Cochez ci-dessous les mots de passe à envoyer, puis cliquez sur Attendre l'autre appareil.
  3. Sur l'autre appareil, ouvrez Passory › Transfert › Recevoir et cliquez sur Se connecter.
  4. Un code (trois mots et un nombre) s'affiche sur les deux écrans : s'il est identique, cliquez sur Les codes sont identiques des deux côtés.

Vérifiez que ce code est exactement le même sur l'autre appareil. S'il est différent, annulez : quelqu'un pourrait tenter d'intercepter le transfert.
